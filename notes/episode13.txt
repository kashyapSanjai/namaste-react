type of testing for developer

1. unit testing
===================
you test your react component in isolation means you test your small unit of your application not the entire application called unit testing
example:- if you want test only header component then there will unit testing for header component

2. integration testing
========================
thing the integration of the component means if there is a big large application there are s many components and these component means talks to each other also called testing feature for example there is search functionality then i have to do integration testing for search where search button in put filed an item component will affect

3. End to End testing (e2e testing)
==================================
testing whole app  like from where user login page  to react app to logout react app

all the testing libraries base is DOM testing library
if we install react using create react app then a test library auto installed but if manually react like parcel,react-router ,  react other parts one by one then we will have to install a testing library also

we need to both react testing library(RTL) and jest library in our project 

Setting up testing environment in our react app
    - (install RTL) npm i -D @testing-library/react
    - (install jest) npm i -D jest
    - (install babel dependencies) npm install --save-dev babel-jest @babel/core @babel/preset-env
    - configue babel
    - configure parcel config file to disable default babel transpilation by creating .parcelrc file
    - (configure jest) npx jest --init
    - (install  jestDOM library) npm install --save-dev @testing-library/jest-dom
    - (install jsdom environment) npm install --save-dev jest-environment-jsdom
